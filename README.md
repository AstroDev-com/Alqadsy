## 📝 ملخص هيكل المشروع (Project Overview)

هذا المشروع عبارة عن تطبيق ويب متكامل (نظام إدارة كتالوج أو متجر إلكتروني) مبني باستخدام أحدث تقنيات **Laravel 12** و **PHP 8.2**.
تم بناء النظام ليكون قابلاً للتوسع، ويدعم تعدد اللغات، ويحتوي على لوحة تحكم إدارية احترافية ذات صلاحيات دقيقة.

### 🛠 التقنيات ونوع الكود (Tech Stack & Code Architecture)
- **نوع الكود والهيكلة:** مبني على معمارية **MVC** (Model-View-Controller) الخاصة بـ Laravel.
- **الواجهات (Views):** تستخدم محرك **Blade** للقوالب (`.blade.php`).
- **نظام الصلاحيات والأدوار:** يعتمد على حزمة `spatie/laravel-permission` لبناء نظام حماية قوي للمسؤولين.
- **تعدد اللغات:** مدمج بحزمة `mcamara/laravel-localization` لدعم لغات متعددة في مسارات الروابط (URLs).
- **التعامل مع الوسائط:** يستخدم `intervention/image` لمعالجة الصور، و `picqer/php-barcode-generator` لتوليد الباركود.
- **ميزات برمجية متقدمة:**
  - تسجيل دخول بواسطة شبكات التواصل (Google & Facebook) عبر `Socialite`.
  - نظام لتتبع نشاطات المستخدمين (Activity Logging) وعمل نسخ احتياطية للموقع (Backup) باستخدام حزم `Spatie`.
  - توفير نظام تصدير واستيراد للجداول بصيغة Excel عبر `maatwebsite/excel`.

### 🌐 الصفحات والأقسام المتوفرة (Pages & Modules)

ينقسم المشروع إلى قسمين رئيسيين:

#### 1. واجهة المستخدم (المنصة العامة - Frontend)
- **الصفحة الرئيسية (`/`):** الواجهة الترحيبية وعرض أبرز المنتجات أو الخدمات.
- **من نحن (`/about`):** صفحة تعريفية بالمشروع أو المؤسسة.
- **معرض الصور (`/gallery`):** صفحة لاستعراض صور الأعمال.
- **المنتجات والتصنيفات (`/category` & `/product`):** تصفح الأقسام واستعراض تفاصيل المنتجات المتاحة.
- **اتصل بنا (`/contact`):** نموذج متكامل لإرسال الرسائل والاستفسارات للإدارة.

#### 2. لوحة تحكم الإدارة (Backend / Dashboard)
*محمية بصلاحيات الدخول (Auth) وتتضمن الأقسام التالية:*
- **الرئيسية (Dashboard):** عرض إحصائيات عامة للمسؤولين.
- **إدارة المستخدمين (Users):** لوحة تحكم كاملة للمستخدمين (إضافة، تعديل، إيقاف، وحذف مؤقت ونهائي).
- **إدارة الأدوار والصلاحيات (Roles & Permissions):** تحديد من يمكنه رؤية أو تعديل أي قسم في لوحة التحكم بدقة متناهية.
- **إدارة الأقسام (Categories):** إضافة وتعديل وحذف تصنيفات الموقع.
- **إدارة المنتجات (Products):** إضافة تفاصيل المنتجات وصورها وتعديلها.
- **صندوق الرسائل (Messages):** متابعة الرسائل الواردة من الزوار عبر نموذج "اتصل بنا" والرد عليها (قراءتها أو أرشفتها).
- **المحادثات (Conversations):** نظام دردشة أو تذاكر داخلي لتبادل الرسائل.
- **الإشعارات (Notifications):** نظام تنبيهات حي لتتبع التحديثات مع خيارات تحديد كـ (مقروء/غير مقروء).
- **تخصيص المظهر (Theme):** إمكانية تغيير وتعديل المظهر العام للمنصة من خلال الإعدادات.
- **الإعدادات العامة (Settings):** صفحة للتحكم الشامل ببيانات الموقع الرئيسية.
- **الملف الشخصي (Profile):** لتحديث بيانات الحساب الشخصي للمدير وكلمة المرور.
