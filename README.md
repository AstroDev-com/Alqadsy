# تقرير تفصيلي عن مشروع القادسي (Alqadsy Web)

## 1. مقدمة عن المشروع
المشروع عبارة عن منصة ويب متكاملة مبنية باستخدام إطار العمل **Laravel 12**، تهدف إلى توفير نظام لعرض المنتجات وتقسيمها إلى تصنيفات، مع ميزات تواصل متقدمة بين المستخدمين (نظام محادثات) ونظام إدارة صلاحيات دقيق.

## 2. التقنيات المستخدمة (Tech Stack)
*   **الخلفية (Backend):** Laravel 12, PHP 8.2+
*   **قاعدة البيانات:** MySQL
*   **الواجهة الأمامية (Frontend):** Blade Templates, Tailwind CSS, Vite
*   **إدارة الأدوار والصلاحيات:** Spatie Laravel Permission
*   **التوثيق والـ API:** Laravel Sanctum
*   **ميزات إضافية:** 
    *   Laravel Socialite (للتسجيل عبر Google و Facebook).
    *   Spatie Backup (لعمل نسخ احتياطية لقاعدة البيانات).
    *   Spatie Activity Log (لتتبع نشاطات المستخدمين).
    *   Laravel Localization (لدعم تعدد اللغات - العربية والأجنبية).

## 3. المكونات الأساسية للنظام

### أ) نظام إدارة المستخدمين والبروفايل
- إدارة حسابات المستخدمين مع دعم الحذف الناعم (Soft Delete) والاستعادة.
- نظام أدوار وصلاحيات مرن (Admin, User, etc) لتحديد من يمكنه الوصول لوحة التحكم.
- واجهة لتعديل الملف الشخصي وتغيير كلمة المرور.

### ب) نظام المنتجات والتصنيفات (Catalog System)
- **الأصناف (Categories):** تنظيم المنتجات في مجموعات منطقية.
- **المنتجات (Products):** إدارة كاملة للمنتجات (إضافة، تعديل، حذف) مع دعم للصور والحالات (Status).
- **العرض (Frontend):** واجهة مستخدم لعرض المنتجات حسب التصنيف وسهولة التصفح.

### ج) نظام المحادثات (Chat System)
- نظام محادثة داخلي يسمح بتبادل الرسائل بين مديري المشروع والمشاركين.
- يدعم إنشاء محادثات جديدة وتتبع الرسائل وقراءتها.

### د) نظام الإشعارات (Notification System)
- إشعارات فورية وتنبيهات داخل الموقع لأي نشاط مهم.
- إمكانية تعليم الإشعارات كـ "مقروءة" أو حذفها دفعة واحدة.

### هـ) نظام الإعدادات (Settings)
- لوحة خاصة للتحكم في ثوابت الموقع (الاسم، الشعار، روابط التواصل، إعدادات البريد) دون الحاجة لتعديل الكود.

### و) واجهة البرمجة (REST API)
- يدعم المشروع API متكامل (بواسطة Laravel Sanctum) لخدمة تطبيقات الموبايل أو أي أنظمة خارجية، ويشمل:
    *   عمليات تسجيل الدخول والبروفايل.
    *   استرجاع المنتجات والأصناف والبحث عنها.
    *   نظام الإشعارات عبر الـ API.

## 4. هيكلية المجلدات الرئيسية
- `app/Models`: يحتوي على نماذج البيانات والعلاقات بينها.
- `app/Http/Controllers`: يحتوي على المنطق البرمجي لكل خاصية في النظام (Admin, Frontend, API).
- `routes/`: مقسمة إلى `web.php` للموقع و `api.php` للتطبيقات.
- `resources/views`: قوالب الواجهة الأمامية ولوحة التحكم.
- `database/`: المجلد المسؤول عن هيكلية قاعدة البيانات والبيانات الأولية (Migrations & Seeders).

## 5. تعليمات التشغيل
1. قم بضبط إعدادات قاعدة البيانات في ملف `.env`.
2. نفذ الأمر `php artisan migrate` للإنشاء.
3. نفذ `php artisan migrate:fresh --seed` لتهيئة بيانات الأدوار والمستخدمين الافتراضية.
4. نفذ `php artisan storage:link` لضمان ظهور صور المنتجات.
